多设备云同步

默认情况下，存档只保存在当前这台设备的浏览器里，所以手机和电脑各有一份互不相通的存档。开启后，存档会保存到你自己 GitHub 账号下的一个私密 Gist，所有设备读写同一份。

  1. 打开 GitHub 新建 Token 页面（classic），只勾选 gist，有效期可选 No expiration，生成后复制。
  2. 第一台设备（数据最全的那台）：粘贴 Token，Gist ID 留空，点「连接」→ 自动创建云存档。
  3. 其他设备：粘贴同一个 Token 和下方显示的 Gist ID，点「连接」→ 下载云端存档覆盖本机。

Token 只保存在本机浏览器，不会写进存档或导出文件。私密 Gist 不会出现在搜索中，但知道链接的人能看到，所以别在任务里写敏感信息。
